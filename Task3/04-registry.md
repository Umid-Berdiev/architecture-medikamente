# 4. Реестр программных и аппаратных средств защиты данных

Реестр — основа для закупки, бюджетирования и аттестации ИСПДн. Колонка «Сертификация» показывает, где
по ПП 1119 / ФСТЭК 21 / ФСБ 378 требуются сертифицированные средства; там, где класс УЗ допускает
несертифицированные, указано «не требуется» и выбран open source под стек IT-отдела.

## 4.3. Что покупаем сертифицированным, а что нет

| Требование | Почему | Средства |
|---|---|---|
| СКЗИ для защиты ПДн при передаче по каналам, выходящим за контролируемую зону (ФСБ 378) | межсайтовый трафик и взаимодействие с госсистемами по закону защищаются сертифицированными СКЗИ | H-05, S-04, S-02, S-03, H-01 |
| Средства защиты от НСД, МЭ, антивирус, DLP при аттестации ИСПДн по УЗ-1/УЗ-2 (ФСТЭК 21) | состав мер для высоких УЗ предполагает сертифицированные СЗИ | H-04, S-19, S-26, S-21/S-09 (с компенсирующими мерами), S-22 |
| Внутри контролируемой зоны между сервисами одной площадки | модель угроз допускает несертифицированные средства при наличии организационных мер и аттестованного периметра; это позволяет использовать open source стека CTO | S-05, S-06, S-10–S-18 |

Окончательный перечень сертифицированных средств фиксируется в модели угроз и техническом задании на
аттестацию, которые разрабатываются в рамках меры C-17 (Task 1).
