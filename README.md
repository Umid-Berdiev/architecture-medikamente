# architecture-medikamente

Проектная работа 10 спринта курса «Архитектор ПО» (Яндекс Практикум): кейс медицинской компании
«Медикаменте». Тема спринта — безопасность и конфиденциальность данных: от анализа текущего состояния до
целевой архитектуры по принципам Privacy by Design, стратегии шифрования и оценки рисков миграции.

В каждой директории есть `README.md` с составом, допущениями и встроенными изображениями диаграмм.

## Диаграммы

Все диаграммы — в формате draw.io (`.drawio`, несжатый XML) с экспортом в PNG. Они генерируются
скриптами из `tools/diagram/` (см. [README](tools/diagram/README.md)), поэтому их можно воспроизвести и
доработать; файлы открываются в draw.io desktop и app.diagrams.net.
