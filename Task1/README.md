## Нотация

Gane-Sarson по гайду Lucidchart: внешние сущности (прямоугольники; пунктир — внешние системы),
процессы (скруглённые блоки с номером и исполнителем), хранилища (открытые справа блоки `D-номер`;
оранжевый пунктир — неучтённое «теневое» хранилище), потоки (стрелки; пунктир — ручной, бумажный
или голосовой канал), границы доверия (фиолетовый пунктир). Красные заметки `R-xx` → `02-security-audit.md`,
зелёные `C-xx` → `05-controls.md`.

## Допущения

* Состав данных в файлах восстановлен по описанию компании и C4-диаграмме; там, где в описании
  нет деталей (способ передачи заявок в лабораторию, порядок резервного копирования), принят наиболее
  вероятный ручной вариант, и это отмечено как «не формализовано».
* Правовые ссылки даны для РФ (152-ФЗ, ПП 1119, приказы ФСТЭК 21 и ФСБ 378, ПП 687, 323-ФЗ,
  приказы Минздрава, 54-ФЗ, 402-ФЗ). Конкретные сроки хранения требуют сверки с номенклатурой дел
  организации и юристом.
* Инструменты подобраны под стек IT-отдела (Java, PostgreSQL, ClickHouse, Elastic, Kubernetes,
  Victoria Metrics); там, где закон требует сертифицированных средств (СКЗИ, МЭ, DLP), указаны классы
  решений, а не конкретные поставщики.

## Как перегенерировать диаграммы

```bash
python3 tools/diagram/gen_dfd.py Task1/dfd
python3 tools/diagram/render.py Task1/dfd/*.drawio
```

Подробнее — в `tools/diagram/README.md`.
